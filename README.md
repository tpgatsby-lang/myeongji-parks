# 명지동 공원·녹지 31곳 — 티맵 바로열기

부산 강서구 명지동의 공원·녹지 31곳을 휴대폰에서 바로 티맵으로 열거나 주소를 복사하는 단일 페이지입니다.
외부 라이브러리 없이 `index.html` 하나로 동작합니다.

- 글씨 20px 이상, 버튼 높이 54px 이상 (어르신 사용 기준)
- 장소마다 번호(두 자리) · 시설명 · 주소, 버튼 2개(티맵 열기 / 주소 복사)
- 상단 번호·이름 검색, 근린공원 / 어린이공원 / 소공원·문화공원 / 녹지 4개 그룹

## 티맵 딥링크

- 기본: `tmap://search?name=<주소 URL인코딩>` (티맵 통합검색 화면으로 이동)
- 안드로이드 크롬·삼성인터넷: `intent://search?name=…#Intent;scheme=tmap;S.browser_fallback_url=<플레이스토어>;end`
  앱이 없으면 플레이스토어로 넘어갑니다.
- 앱이 2초 안에 열리지 않으면 주소 복사와 앱 설치 링크가 있는 안내창이 뜹니다.

## 배포

GitHub Pages. `main` 브랜치에 올리면 `.github/workflows/pages.yml`이 자동으로 배포합니다.
(저장소 Settings → Pages → Source가 "GitHub Actions"여야 합니다. 워크플로가 처음 실행될 때 자동으로 설정합니다.)
